# IDE note: use VS Code for EV3 deployment

This project uses Pybricks MicroPython 2.0 on the LEGO MINDSTORMS EV3. The supported project creation, transfer and run workflow documented by LEGO/Pybricks uses Visual Studio Code and the LEGO EV3 MicroPython extension.

PyCharm and other Python editors can edit the source files, but they do not provide the LEGO EV3 extension's project transfer and run integration. A normal desktop Python interpreter also cannot import the EV3 hardware modules or emulate the brick.

For installation, project layout, USB connection, F5 transfer/run, syntax checking and troubleshooting, see [VS Code setup](vscode.md).
