# VS Code setup for EV3 Pybricks MicroPython

This project targets **Pybricks MicroPython 2.0 on the LEGO MINDSTORMS EV3**. EV3 uses the older v2.0 runtime; instructions for Pybricks 3.x and newer Powered Up hubs do not apply.

## 1. Install the computer software

1. Install [Visual Studio Code](https://code.visualstudio.com/).
2. Open Extensions in VS Code (`Ctrl+Shift+X`).
3. Search for and install **EV3 MicroPython** by LEGO Education (the extension identifier is `lego-education.ev3-micropython`).
4. Install the Microsoft Python extension if you want Python editing support and syntax highlighting. It is not the tool that transfers code to the brick.

The LEGO EV3 extension provides the EV3 project workflow and brick transfer/run integration. For EV3, do not substitute the newer Pybricks Code browser editor or assume that the Pybricks 3.x `pybricksdev` workflow is compatible.

## 2. Prepare the EV3 brick

You need an EV3 brick, a microSD card between 4 GB and 32 GB, a card reader, and a mini-USB cable.

1. Back up anything you need from the microSD card. Writing the EV3 MicroPython image **erases the entire card**.
2. Download the EV3 MicroPython microSD image from the official [installation guide](https://pybricks.com/install/mindstorms-ev3/installation/).
3. Use a suitable image-writing utility to write the image to the card.
4. Insert the card while the EV3 is powered off, then turn the brick on. Wait for the status light to become green.
5. Connect the brick to the computer using the mini-USB cable.

## 3. Open this project in VS Code

The most reliable starting point is to use the EV3 MicroPython extension's **Create a new project** command once. Choose a folder, then copy this repository's Python files and folders into that project folder, keeping `main.py` at the top level.

You can also use **File → Open Folder** to open an existing EV3 MicroPython project. The extension expects the project folder—not an individual `.py` file—to be open.

Suggested layout:

```text
ev3-project/
├── main.py
├── test_ev3.py
├── examples/
│   ├── hello_brick.py
│   ├── motor_basics.py
│   ├── drive_base.py
│   └── sensors.py
└── docs/
```

## 4. Transfer and run

1. Turn on the EV3 and connect its mini-USB cable.
2. In the EV3 MicroPython view/extension, select or configure the USB-connected brick as described in the extension prompts.
3. Open the top-level `main.py`.
4. Press **F5** (or use the Run/Debug start control). The extension transfers the project to the brick and runs the main program.
5. Stop a running program using the on-screen stop control or the EV3 back button.

The first-run `main.py` in this repository only clears and writes to the display and plays a short beep. It does not move motors, so it is a low-risk initial connection check.

To run another example, copy its contents into `main.py` or temporarily make that example the main program. Check the port and physical wiring before running motor or sensor code.

## 5. What works locally versus on the brick?

- **On the computer:** VS Code can edit files and perform basic syntax checks.
- **On the EV3:** Pybricks hardware modules such as `pybricks.hubs`, `pybricks.ev3devices` and `pybricks.robotics` are provided by the EV3 runtime.
- **Local CPython is not an EV3 simulator.** Running `python main.py` on Windows/macOS/Linux will fail to import the EV3 modules. Use the LEGO extension to transfer and execute hardware programs.
- A local syntax-only check can be done without running the program: `python -m py_compile main.py test_ev3.py`. This checks Python syntax but does not validate hardware APIs or wiring.

For code completion, the [Pybricks API repository](https://github.com/pybricks/pybricks-api) provides Python stubs. The repository's guidance explains how to enable them with the language-server settings generated by the LEGO extension. Treat stubs as editor assistance, not as an installable EV3 runtime.

## Troubleshooting

- **Brick not found:** Confirm it is powered on, the microSD image booted fully (green status light), and the mini-USB cable supports data.
- **Import errors on the brick:** Confirm the brick booted from the EV3 MicroPython image and that the program targets Pybricks v2.0.
- **Import errors on the computer:** Expected when running EV3 hardware code with ordinary desktop Python. Use F5 through the EV3 extension.
- **Motor moves the wrong way or not at all:** Stop the program and verify the output port, motor type, direction and mechanical setup.
- **Sensor error or implausible readings:** Verify the sensor is supported and attached to the input port specified in the script.
